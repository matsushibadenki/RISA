# G3.2 role-backed online lifecycle ablation — development control

## English

The manifest fixes five development seeds, all seven existing arms, 12 B and 12 A2 Events, native two-hop readout, context-conditioned discovery and one validation boundary after the last B Event. Every arm has the same **1,200-label maximum**. Actual consumption differs because missing proposals do not consume labels: 1,200 for full/no-dormancy, 800 for split-only/no-merge, zero for merge-only/no-split/none. This is equal access to a budget, not equal consumed supervision. There is no A1 adoption or A2 revalidation.

Fixed fixture contracts validate A-role indoor, A-role sheltered and their warm union, in that order. Each contract uses 200 independent development and 200 final applicability labels with query-backed action/role matching. Label episode/source namespaces are disjoint from training, scoring and other contracts. The existing gain, confidence interval, lineage and false-generalization gates are unchanged. Labels enter the real online state through the drift runner, after prediction and observation; the result is no longer a disposable-copy adoption diagnostic. These applicability labels are extra supervision and are not learned Events.

| Arm | Consumed labels per seed | A nuisance correct after B validation /120 across seeds | After first A2 update /120 | A2 exit /120 |
| --- | ---: | ---: | ---: | ---: |
| full | 1,200 | 80 | 16 | 0 |
| split-only | 800 | 80 | 48 | 0 |
| merge-only | 0 | 0 | 0 | 0 |
| no-split | 0 | 0 | 0 | 0 |
| no-merge | 800 | 80 | 48 | 0 |
| no-dormancy | 1,200 | 80 | 48 | 0 |
| none | 0 | 0 | 0 | 0 |

Each full run adopts two specialized parents and one merge, then makes two parents dormant. No-dormancy adopts the same candidates without dormancy. Removing the adopted merge at the B boundary changes 80/240 combined A/B nuisance predictions in full and zero in no-dormancy: active parents already provide the same answers. No arm predicts B nuisance effects correctly at that boundary. Thus the immediate full accuracy equals no-merge despite 400 additional labels, and merge is necessary only after its alternative parents have been made dormant.

Evidence updates regenerate candidates or reset evaluation when supporting/counterexample sets change. The existing unchanged-evidence check deliberately prevents stale adoption from carrying forward. After the first A2 Event, full retains only 16/120 correct A nuisance predictions, versus 48/120 without dormancy; after 12 A2 Events every arm has zero. This does not prove a general causal harm from dormancy, but identifies a concrete interaction between validation invalidation and sleeping parents that requires an explicit reactivation/revalidation policy.

Both latest and count two-hop context-subset tables retain **120/120 A and 120/120 B nuisance predictions** after B and A2, with zero consumed adoption labels. They share the deterministic role extractor with RISA and receive the same observed Events. Their unused label allowance is 1,200. RISA does not outperform these controls.

The exact-context drift runner reports identical B recovery counts across arms: 5, 5, 6, 5, 7 Events for the ordered seeds, and A2 recovery zero. These are exact-context metrics, not nuisance recovery. A1 nuisance accuracy is zero, so a 95% A1-relative nuisance recovery threshold would be vacuous; we report absolute checkpoint correctness instead and do not call the post-B A gain retained A1 knowledge. Replay work and structural touches remain in the raw runner output; candidate context specialization is not Primitive context splitting. Primitive split and informative lifecycle-benefit gates remain open. This is a development control, not an independent G3.2 final or a complete information-matched efficacy experiment.

PredictionResult reload equality is checked at A1, before/after online adoption, after the first A2 update and at A2 exit: 175 checkpoints. A rejection test verifies that insufficient label reservation fails before candidate mutation. The manifest and JSON preserve actual label IDs, decisions, drift metrics and merge-removal diagnostics.

Next: audit orphaned dormancy when a validated descendant expires, compare safe parent reactivation against independently budgeted query-backed extension validation, and retain the strong subset baselines. Freeze an informative contrast before independent final seeds.

```sh
python -m pytest -q tests/test_role_online_ablation.py
```

## 日本語

5開発seed・7条件で、B終了直後に実際の学習状態へ採用評価を適用した。全条件に同じ1,200ラベル上限を与え、消費は全機構あり/休眠なし1,200、split-only/mergeなし800、他0。消費量が等しい比較ではなく、利用可能予算が等しい比較である。A役割のindoor、sheltered、その和集合という固定契約を、各200 development＋200 finalの独立query付きラベルで検証した。既存の採用閾値・反例・独立性条件は変更していない。A1採用とA2再検証は行わない。

全機構ありで各seedの親2候補・merge1候補を採用し、親2候補を休眠させた。B検証直後の未見文脈A正解は5 seed合計80/120件で、mergeなしと同じ。mergeを除くと全機構ありでは80/240件のA/B予測が変化するが、休眠なしでは0件。mergeの独自効果と親の予測を置き換えた効果を区別する必要がある。

A2最初の更新後は全機構あり16/120件、mergeなし・休眠なし48/120件、A2終了時は全条件0件となった。証拠集合の更新で検証済み採用が失効する既存仕様と、親の休眠の相互作用が次の監査対象となる。2-hop文脈部分集合表は追加採用ラベル0でB/A2終了時のA・B各120/120件を維持した。RISAの優位性は示されていない。

具体文脈のB回復は全条件でseed順に5/5/6/5/7 Event、A2回復は0。これは未見文脈の回復ではない。A1の未見文脈正解率が0のため、その95%を回復閾値にする評価は無意味であり、絶対正解件数を報告した。Bで獲得したA予測をA1知識の保持とは呼ばない。175 checkpointで保存前後の完全PredictionResult一致を確認。Primitive split・有益な機構対比・独立finalのゲートは未達。次に採用失効時の親再活性化と、予算を明示した独立再検証を比較する。

## 简体中文

在五个开发seed、七种条件下，于B结束后对真实在线状态进行采纳验证。所有条件共享1,200标签上限；完整/无休眠消耗1,200，仅分裂/无合并800，其余0。这是可用预算相同，而非实际监督消耗相同。固定验证A角色indoor、sheltered及其并集，每个契约使用200开发和200最终独立query标签，保持现有采纳门槛与反例约束。不进行A1采纳或A2重新验证。

完整条件每个seed采纳两个父候选及一个合并候选，并休眠两个父候选。B验证后A未见情境正确数为80/120，与无合并相同。移除合并在完整条件改变80/240个A/B预测，在无休眠条件改变0个，说明当前合并主要替代了休眠父候选的预测。

A2首次更新后完整条件正确16/120，无合并/无休眠48/120；A2结束所有条件为0。证据变化使验证失效，与父候选休眠的交互需要进一步审计。两个共享两跳角色提取器的情境子集表，无需采纳标签即可在B/A2结束保持A、B各120/120，RISA未显示优势。

精确情境B恢复在各条件相同，为5/5/6/5/7 Event，A2为0；这些不是未见情境恢复指标。A1未见情境正确率为0，使用其95%作为恢复阈值没有意义，因此报告绝对正确数。B中新获得的A预测不称为A1知识保留。175个checkpoint保存前后完整PredictionResult一致。Primitive分裂、有益机制对比及独立最终评估仍未通过。下一步比较验证失效后的父候选安全重新激活，与预算明确的独立重新验证。
