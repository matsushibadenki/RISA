# RISA 構造補間と構造平滑化のメモ

## 1. 目的

この文書は、RISA のように知識を重みではなく構造として保持するアーキテクチャにおいて、

- どのように精度向上を考えるか
- 従来の重み補間に相当するものは何か
- 継続学習で何を更新対象にするか

を整理するための設計メモです。

現時点の結論は次です。

> RISA では、精度向上の主役は「重みの補間」ではなく、「構造の補間」と「構造の平滑化」になる可能性が高い

---

## 2. Transformer で補間されているもの

Transformer では、基本的に

```text
入力
  ->
重み W
  ->
出力
```

という形で計算が行われます。

このとき改善の中心は、重み空間を少しずつ滑らかに移動させることです。

例:

- SGD
- Adam
- LoRA
- Weight Averaging
- EMA

つまり、

```text
W1
  ->
W2
  ->
W3
```

と、重みそのものを更新していく。

---

## 3. RISA では何を改善するのか

RISA では、知識が主に

- 概念
- 関係
- 状態遷移
- 文脈

として明示構造に保存されます。

したがって改善対象は

```text
構造
  ->
構造
```

の変換になります。

例えば、

```text
犬
 │
 ├ 哺乳類
 ├ ペット
 └ 狼
```

という概念周辺構造を、経験や比較を通してより予測に役立つ形へ整えていく。

ここで更新されるのは巨大な重み行列ではなく、

- 接続の有無
- 接続の信頼度
- 構造の共通部分
- 例外の分岐
- 抽象概念の境界

です。

---

## 4. 構造補間とは何か

RISA における構造補間とは、

> 近い構造同士の共通性・差分・信頼度を利用して、構造全体をより予測しやすく、再利用しやすい形へ滑らかに更新すること

と整理できます。

これは数値補間より広い概念です。

対象には少なくとも以下が含まれます。

- サブグラフの統合
- 関係信頼度の更新
- 概念境界の修正
- 類似構造からの関係提案
- 文脈差による分岐

---

## 5. 想定できる補間アルゴリズム

### 5.1 グラフ補間

二つ以上の近い構造を比較し、共通部分と差分を統合する。

例:

```text
犬
 ├ 哺乳類
 └ ペット
```

```text
犬
 ├ 哺乳類
 ├ 家畜
 └ 狼
```

これらを比較して、

```text
犬
 ├ 哺乳類
 ├ ペット
 ├ 家畜
 └ 狼
```

のように統合候補を作る。

これは単なるマージではなく、

- どの文脈で成立するか
- どの接続が根拠豊富か
- どの接続が例外を生むか

を見ながら行う必要があります。

### 5.2 信頼度補間

各関係に、単なる接続有無だけでなく確信度を持たせる。

例:

```text
犬 -> 哺乳類 0.99
犬 -> 家畜   0.25
犬 -> 狼     0.70
```

新しい経験や情報源に応じて、

```text
0.25
  ->
0.52
```

のように更新する。

ここで補間されるのは重みではなく、**関係の確からしさ** です。

### 5.3 構造編集による補間

構造そのものを成長させることで、予測精度を上げる。

例:

```text
犬
 │
 ├ 動物
 ├ 哺乳類
 ├ ペット
 └ 四足歩行
```

が、追加観測によって

```text
犬
 │
 ├ 動物
 ├ 哺乳類
 ├ ペット
 ├ 四足歩行
 ├ 愛玩動物
 ├ 災害救助
 └ 盲導犬
```

へ育つ。

これは単なる情報追加ではなく、予測や説明で使える構造の増強です。

### 5.4 埋め込みとのハイブリッド補間

RISA は構造型アーキテクチャですが、各ノードや関係に小さな埋め込みを持たせる案は有望です。

```text
構造
  +
小さな Embedding
```

とし、構造は主記憶、埋め込みは曖昧近傍探索や近似比較に使う。

この場合、

- 構造は明示的に更新する
- 埋め込みは局所的に微調整する

という二重の補間が可能になります。

### 5.5 サブグラフ統合

異なる情報源や異なる時期の知識を、差分比較して統合する。

例:

- A さんの知識
- B さんの知識
- 過去の世界モデル
- 現在の世界モデル

を比較して、

- 一致する部分は強化
- 矛盾する部分は文脈分岐
- 弱い仮説は保留

のように扱う。

これは、LLM の単一重み更新ではやりにくい強みになりえます。

---

## 6. 構造平滑化という考え方

RISA らしい精度改善として特に重要そうなのが、**構造平滑化（Structural Smoothing）** です。

これは、

> 構造が似ている概念同士の周辺関係を比較し、強い共通性がある場合に、慎重に関係候補を提案・補完する

という考え方です。

例:

```text
犬
│
├ ペット
├ 哺乳類
└ 散歩
```

```text
猫
│
├ ペット
└ 哺乳類
```

が大量に存在すると、RISA は

```text
犬と猫は構造的に近い
```

と判断できるかもしれません。

すると、

```text
犬
│
├ ペット
├ 哺乳類
├ 散歩
└ 愛玩動物
```

```text
猫
│
├ ペット
├ 哺乳類
├ 愛玩動物
└ 室内飼育
```

のように、近い構造同士から新しい関係候補を提案できます。

これは重み空間の滑らかな補間に対して、**構造空間での滑らかな補完** に相当します。

---

## 7. 補間対象は構造だけではない

RISA では、関係や概念に属性を持たせることで、より柔軟な補間ができます。

重要候補:

- 信頼度
- 時間
- 文脈
- 情報源

例えば、

- 高信頼な新情報源なら関係信頼度を上げる
- 古いが更新されない知識は徐々に下げる
- 科学文脈では成立するが日常文脈では弱い関係を分ける
- 観測由来と推論由来を区別して扱う

といった運用ができる。

したがって補間は、

> 構造 + 関係属性 + 時間 + 文脈

の複合更新として捉えるべきです。

---

## 8. RISA における最適化の見方

Transformer が重み空間を最適化すると言えるなら、RISA は

> 構造空間を最適化する

と捉えられます。

ここでの最適化目標は、単なる圧縮では不十分です。

少なくとも次の複合目標が必要です。

- 予測精度が上がる
- 構造が再利用しやすくなる
- 例外を保持できる
- 継続学習で壊れにくい
- 説明経路が保たれる

つまり、RISA の学習とは「知識を覚えること」だけではなく、

> 知識ネットワーク全体を継続的に整えること

でもあります。

---

## 9. MVP-1 への含意

MVP-1 ですぐ全部を実装する必要はありません。  
ただし、将来へつながる最小要素は早めに入れてよいです。

MVP-1 で現実的な候補:

- 関係ごとの `reliability` 更新
- 共有効果に基づく簡易概念統合
- 類似 actor 間の関係提案のログ出力
- 情報源や文脈タグを保持したままの更新

MVP-2 以降の候補:

- Structural Smoothing
- 文脈別信頼度補間
- サブグラフ差分統合
- 小さな埋め込みとのハイブリッド
- 例外増加時の概念分裂

---

## 10. 設計上の注意

構造補間は強力ですが、無制限に行うと誤った一般化を生みます。

主なリスク:

- 類似して見えるだけの概念を誤って統合する
- 例外を消してしまう
- 文脈差を潰してしまう
- ノイズ経路が平滑化で増幅される

したがって、補間には少なくとも次のガードが必要です。

- 十分な evidence
- 文脈一致
- 予測改善の確認
- 後戻り可能な仮説扱い

RISA の補間は、常に **仮説的編集** として扱うのが安全です。

---

## 11. 現時点の結論

RISA における精度向上は、

- 重みの微調整

ではなく、

- 構造の統合
- 関係信頼度の更新
- 類似構造からの候補補完
- 文脈付きの再編成

として捉える方が自然です。

この意味で、RISA は重み空間を学習するというより、

> **構造空間を継続的に整流・補間・再編成する知能**

として設計するのが筋が良いと考えられます。
