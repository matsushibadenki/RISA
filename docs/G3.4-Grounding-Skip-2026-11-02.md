# G3.4: Reservoir collection cost / 標本収集の費用 / 采样成本

`GroundingSampleWindow(policy='skip')` と `GroundingSampleSchedule(policy='skip')` で選択できる。既定の `reservoir` は従来の乱数列を維持する。新方式は最初の k 件を保持し、以降は次の入れ替え位置だけを先に決める。飛ばすのは乱数生成と標本の組み立てであり、照合・件数の記録は全件行う。役割対とidentityは一体で採取する。

The opt-in sampler uses [Li’s Algorithm L](https://doi.org/10.1145/198429.198435). After filling the reservoir, it maintains a threshold per Primitive, draws the geometric gap to the next admission and replaces one uniform slot. The log threshold and stable logarithms handle weights close to one. It still visits each binding. The old seeded sampler is the default; different policies need not select the same individual bindings.

显式 `skip` 方式为每个Primitive预先计算下一替换位置，跳过中间的随机调用，仍访问并计数全部照合。角色与identity整体采样。默认方式和默认随机序列保持不变；不同方式的具体样本无需相同。

**測定方法 / Method / 方法.** 収集単体は1 Primitive、容量8、32件と8,192件。初期化・全件observe・標本出力を64 sampling seedで計測し、乱数API呼び出し数は別の非計時リプレイで数える（内部の乱数ビット数ではない）。検索全体は独立・結合・actor集中の3開発world、区間32/512 query、同一辞書予算。ID順・頻度・通常reservoir・skipの4方式を3 hash seed × 4実行順で逐次実行する。query総数とPrimitiveごとの照合数は異なる。

World totals sum measured build, learning, query (including observer setup/removal and export), calibration and rebalance CPU. State audits and save/reload are outside the timers. Each policy receives its own bounded samples (sampling seed 0); every full answer is compared with evidence scan, including counterexamples. Compare saved bytes within process and edge-order-normalized content across processes. These are development workloads, not production traces.

单独计时含初始化、全部observe和样本输出，随机调用数在独立重放中统计。整体计时包含构建、学习、查询及观察器设置/解除、输出、校准和重分配。与全扫描比较完整结果及反例；同process验证保存字节，跨process仅规范edge顺序后验证内容。开发world不代表生产流量。

Across 72 trajectories, 102,912 complete-result cases, 288 state checkpoints and 288 save/reloads agreed. At 8,192 bindings the collector's paired CPU change was −44.1%; at 32 it was +16.4%. End-to-end paired changes ranged from −1.0% to +2.3%. Keep the seeded default. RNG calls count high-level requests, not underlying bits. Hash seeds vary Python hash order; arm order rotates separately. The sampling seed of the world experiment is fixed.

72条轨迹中102,912个完整结果、288个状态检查点及288次保存恢复一致。8,192次照合时采样CPU降低44.1%，32次时增加16.4%。整体配对变化为−1.0%至+2.3%，保持默认方式，仅在单Primitive长照合流中显式选择。此次结果不足以确定自动切换阈值。
