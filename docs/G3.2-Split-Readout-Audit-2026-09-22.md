# G3.2 split readout audit / 分裂readout監査 / 分裂读取审计

Status: [Done] development diagnosis; a beneficial causal split contrast remains [Next].

In the [observable-return-cue, 20% observation-noise experiment](G3.2-Observable-Return-Cue-2026-09-22.md), the optional contextual split proposal executes two Primitive splits in every seed. The new `B_split_variant_audit` records each B-scope variant's context, produced effect, evidence support, adoption status, and agreement with the fixture's latent B rule at the B boundary. Across the five seeds, this arm creates four B-scope variants per seed; adopted off-rule variants number **2, 1, 2, 1, 0**. These variants arise from noisy observations in the same context. The regular split-on arm executes one split in seed 71 and none in the other four; split-off executes none. All three arms nevertheless have the same B/A2 prediction trajectories and recovery counts.

For seed 11, the optional proposal adopts both a cold/indoor/B variant supported by eight observations and a warm/indoor/B variant supported by two flipped observations. It also adopts a warm/outdoor/B variant supported by eight observations and a cold/outdoor/B variant supported by two flipped observations. This demonstrates that execution and adoption alone do not imply selectivity for the latent rule. In the predictor, `primitive_support` contributes at most **0.05** to an effect score; context-specific grounded actor/target/role evidence and a recent-outcome bonus can be much larger. A read-only Primitive removal at the B boundary changes the score but not any predicted effect. Increasing the Primitive weight solely to force a difference would not establish better predictions and could amplify the adopted off-rule variants.

The audit uses the synthetic world's known latent rule only **after training** to classify variants. It does not feed that rule into learning, candidate adoption or prediction. A different world may legitimately have multiple effects in one context; `off_rule` here is specific to this single-effect fixture. This is a mechanism-path diagnosis, not a final split evaluation or an argument for changing default thresholds.

The predictor formerly gave a split variant partial context credit when one tag matched but another contradicted it: for example, an `indoor|regime:A` variant could support `indoor|regime:B`. It could also enter the candidate-effect list, selected Primitive outcome, and supporting paths without checking context. Split variants now require exact equality of the complete normalized context tag set in **all four predictor paths**. General unsplit Primitives retain their broader partial-match semantics. A focused regression test checks both paths. Re-running all seven development manifests changed **zero** rows of the recorded B/A2 recovery, return retention, B-exit accuracy or executed-split counts. This fixes split-variant readout leakage, but it is not evidence that splitting helps prediction.

Primitive adoption still uses support, validation and Replay derived from the same learned Event history. These are not independent held-out labels. Changing the global adoption threshold after seeing the noisy fixture would conflate calibration with validation; the off-rule audit remains a development diagnostic until a separate evidence budget and final test are fixed.
