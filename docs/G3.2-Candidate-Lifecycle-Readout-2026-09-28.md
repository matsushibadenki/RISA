# G3.2 Candidate Lifecycle Readout Attribution

## 日本語

候補採用直後のA1状態で、学習Eventと重ならない24 probeを5 seedに適用した。元状態は変更せず、コピー上で次の介入を行った。

1. 採用済み`merged`候補だけを推論indexから除外する。
2. mergeは残し、mergeが置換して休眠させた祖先候補だけを再活性化する。

`full`と`no_split`では各seedに採用済みmerge 1件と休眠祖先2件がある。merge除外は合計120予測の効果を1件も変えず、accuracyは1.0のままだった。ただし平均予測scoreは全seedで0.2変化した。休眠祖先の再活性化は予測効果・accuracy・scoreを変えなかった。`no_dormancy`と`merge_only`では親候補が既にactiveなため、merge除外のscore差も0だった。

この世界ではmergeは同じ効果への補助scoreを提供するが、予測判断を担っていない。dormancyは冗長な祖先をindexから除くものの、readout結果を変えない。採用にはarm当たり1,200教師ラベルを使うため、この結果からmerge/dormancyのdrift利得は主張できず、独立finalへ進めない。次は、履歴キーを直接選ばない観測可能な復帰手掛かりと、候補だけが一般化できるheld-out queryを持つ開発worldを設計する。

## English

We evaluated 24 probes disjoint from learned Events at the post-adoption A1 boundary over five seeds. Disposable copies received two interventions: remove only adopted merged candidates from the inference index, or retain the merge while reactivating only the dormant ancestors it replaced.

The `full` and `no_split` arms each contain one adopted merge and two dormant ancestors per seed. Removing the merge changes zero of 120 predicted effects and leaves accuracy at 1.0, although mean prediction score changes by 0.2 in every seed. Reactivating dormant ancestors changes no effect, accuracy, or score. In `no_dormancy` and `merge_only`, the parents are already active and removing the merge produces no score change either.

In this world, the merge supplies an auxiliary score for an already selected effect rather than controlling the prediction decision. Dormancy removes redundant ancestors from the index without changing readout. Adoption costs 1,200 supervised labels per arm, so this result does not establish a drift benefit and does not justify an independent final run. The next development world must provide an observable return cue that does not directly select a history key and held-out queries for which candidate structure is necessary for generalization.

## 简体中文

在候选采纳后的A1边界，我们用五个seed、每个seed 24个与学习Event分离的探针进行评估。仅在一次性副本上执行两种干预：从推理索引移除已采纳的合并候选；或保留合并候选，仅重新激活被其替代的休眠祖先。

`full`与`no_split`中每个seed均有1个已采纳合并及2个休眠祖先。移除合并候选后，120次预测的效果均未改变，accuracy仍为1.0，但每个seed的平均预测score变化0.2。重新激活休眠祖先不会改变预测效果、accuracy或score。`no_dormancy`与`merge_only`的父候选本来就是active，因此移除合并候选连score也不改变。

在该环境中，合并候选只为已经选中的效果提供辅助score，并不控制预测决策；休眠机制从索引移除冗余祖先，但不改变读取结果。每组采纳需1,200个监督标签，因此尚不能据此主张漂移收益，也不进入独立final评估。下一步开发环境应提供不会直接选择历史键的可观察返回线索，并加入只有候选结构才能泛化的独立留出query。
