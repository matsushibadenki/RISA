# G3.3 End-to-end protocol / 全処理評価契約 / 端到端评估协议

日本語: この評価は実際の`train_events`を通り、graph、学習前予測、学習、代謝、候補発見、Replay、適応を既定設定で実行する。1000 Eventごとのchunk、chunkあたり32件のReplay、seed 17、1千・1万・10万Event、各規模45秒を評価前に固定する。8 actor、4 action、3 context、12 Eventの独立episodeからなる固定語彙の合成負荷であり、汎化の証明には使わない。

English: Run the real `train_events` path with default graph updates, pre-update prediction, learning, metabolism, discovery, Replay and adaptation. Freeze 1,000-event chunks, 32 Replay events per chunk, seed 17, scales 1k/10k/100k and a 45-second process budget per scale before evaluation. The synthetic bounded-vocabulary load has eight actors, four actions, three contexts and independent twelve-event episodes; it does not establish generalization.

简体中文: 使用真实`train_events`路径，默认执行graph更新、学前预测、学习、代谢、候选发现、Replay及适应。评估前固定每chunk 1000 Event、每chunk最多32次Replay、seed 17、1千/1万/10万规模及每规模45秒进程预算。合成负载含8个actor、4个action、3个context及独立的12 Event回合，不证明泛化。

日本語: 学習完了後に12 queryの予測、予測同値性を確認するreadout凝縮、1 queryの2-step計画、原子的保存、読み込み、全PredictionResultの比較を行う。保存処理は既存の保存前復元検証も含む。active structuresは採用Primitive数であり、active graph node数とactive candidate数も別に記録する。候補数とdescription-length deltaは現在の候補の値であり、累積生成数や情報理論的符号長ではない。

English: After training, measure twelve predictions, equivalence-checked readout compaction, one two-step planning query, atomic save, load and full PredictionResult equality. Save includes the existing pre-write reconstruction validation. Active structures mean adopted Primitives; active graph nodes and candidates are separate counts. Candidate counts and description-length deltas describe the current candidates, not cumulative generation or information-theoretic code length.

简体中文: 学习完成后测量12次预测、验证预测等价性的readout压缩、一次两步规划query、原子保存、读取及完整PredictionResult一致性。保存含现有的写入前重建验证。active structures指已采纳Primitive数量；活跃graph节点及候选另行记录。候选数及description-length delta为当前候选指标，不代表累计生成数或信息论编码长度。

日本語: 規模ごとに独立processと状態を使い、時間上限でprocessを終了する。途中結果は最後に完了したchunkまたはstageの値であり、未完了chunkの時間・Eventを含めない。process全体の時間は別に記録する。全規模完了と凝縮・復元後の完全一致を満たす場合のみ`profile_complete`とする。100万Eventはこの条件を満たさない限り実行しない。条件を満たしても専用計算資源の検討を先に行う。

English: Each scale uses an independent process and state, terminated at its budget. Partial results contain only the last completed chunk or stage, excluding unfinished chunk work; process wall time is reported separately. Require all scales and exact post-compaction/reload results for `profile_complete`. Do not attempt 1M if this fails; even a pass requires a separate capacity review first.

简体中文: 每个规模使用独立进程和状态，达到预算即终止。部分结果仅包含最后完成的chunk或stage，不含未完成chunk工作，进程总时间另行记录。全部规模完成且压缩/恢复结果完全一致才判为`profile_complete`。失败则不测试100万；即使通过也先评估专用计算资源。

日本語: 学習の代謝worklistは既定で有効。公開予測は全根拠を保持し、学習前検証だけが不使用の根拠出力を省く。同値性は[凍結Git比較](g3-incremental-equivalence-results.json)で別途確認する。今回の規模測定はこの実装に更新した同一manifestを使用する。

English: The training metabolism worklist is enabled by default. Public predictions retain complete provenance; only pre-update validation omits unused provenance output. A separate [frozen Git comparison](g3-incremental-equivalence-results.json) verifies equivalence. The scale rerun uses the same manifest with this implementation.

简体中文: 训练默认启用代谢工作表。公开预测保留完整来源，仅学前验证省略不使用的来源输出。通过[冻结Git比较](g3-incremental-equivalence-results.json)单独验证等价性，规模复测使用相同manifest及更新后的实现。
