# G3.4 Window sampling / 区間全体からの標本化 / 全区间采样

## 日本語

`GroundingSampleWindow`を追加した。呼出し側が区間ごとに作成し、実際に発生したPrimitive照合を`observe`へ渡し、区間末の`samples()`をcalibrationへ渡す。通常queryへ自動で収集処理は入れない。`policy='reservoir'`はAlgorithm Rにより、区間内の全照合位置を同じ確率で選ぶ。`policy='prefix'`は比較用の先頭例方式。容量はPrimitiveごとに1〜64件で、各照合のactor役割・actor・target・target役割を一組として保持する。rolesはtupleに固定し、同じ照合が複数回起きた重みも保持する。

Primitive IDと明示seedからhash順序に依存しない乱数系列を作る。毎区間同じseedなら、同じ入力列の標本は同じになり、前回の厳密な標本比較による計測値の再利用が可能。一方、後半の変化が標本に入れば再計測される。ただし有限標本なので変化検出を保証しない。Primitive間の入力の混在は各Primitiveの選択列を変えない。返す標本は元の照合順に並べる。個数上限はPrimitiveごとであり、Primitive総数・入力文字列長・RSSを制限するものではない。reservoirには乱数生成器のメモリも必要。

比較はID・頻度・prefix8・reservoir8・reservoir32の5方式。後3方式は利益配分・`reuse=True, max_reuses=2`で同じ条件。独立/結合/集中world、各32/512 queryの4区間。先頭8 queryは同じにし、1区間目の後半は有効query、2区間目以降の後半はrole/identity反例または未知targetへ切り替える。集中worldでは全queryが同じPrimitiveを参照するため、先頭8照合が完全に同じでも後半が変わる対照になる。他worldはqueryごとのPrimitive参照数が異なるため、先頭8 queryが同じでも全Primitiveの先頭8照合まで同じとは限らない。

1/2/3区間目で実照合を収集しcalibrationを行う。3区間目前に追加学習、4区間目前にidentity訂正を行う。全方式で同じquery・更新・予算を使い、3 hash seed ×5巡回先行順、15 processを逐次実行する。PRNGのsampling seedは既定0で固定し、hash seedの変更をsampling seedの独立反復とは扱わない。別途512個のsampling seedで位置ごとの選択頻度を回帰検証する。

標本の品質は、タイマー外でID方式の実照合列を全件取得し、Primitiveごとの完全な照合tupleの経験分布とのtotal variation距離（TV、0が一致、1が最大差）を測る。Primitiveの参照数で重み付けして区間の値とする。query・標本の収集/出力・calibration・再利用判定・構築・追加学習・最終再配置を総CPU/wallに含める。TV監査・反例検証・heap測定・保存は時間の対象外。collectorとindexの保持メモリを別に見積るため、両方が共有する文字列を含み単純和は厳密な合計ではない。

全timed query・全反例panelの完全結果を全走査と照合し、区間ごとの保存用state、実保存/復元を比較する。process間は完全結果と、既存graph edge配列順だけを正規化した保存内容のdigestを比較する。時間由来の配分は一致を要求しない。実運用ログは未提供であり、開発worldでの検証に限る。

## English

Add explicit `GroundingSampleWindow`: callers observe actual Primitive bindings and pass the boundary snapshot to calibration. No default query hook is installed. Uniform Algorithm R samples all positions; prefix is the control. Capacity1..64 is per Primitive, retaining complete actor-role/actor/target/target-role tuples and repeated-access weights. Freeze roles and return retained samples in stream order. A per-ID seeded PRNG avoids Python hash dependence and interference between primitives. Identical streams/seeds yield identical samples for exact cache reuse. Changed tails can invalidate reuse, but finite samples cannot guarantee drift detection. This is not a global memory/RSS limit; PRNG state also costs memory.

Compare ID/frequency/prefix8/reservoir8/reservoir32; sampled arms share benefit ranking and reuse(max2). Independent/coupled/concentrated worlds, four windows of32/512 queries, identical first eight queries followed by valid tails in window1 and rejection/unknown-target tails thereafter. The concentrated world keeps one Primitive, giving an exact identical-binding-prefix control. Other worlds may have fewer than eight prefix bindings for some primitives. Collect/calibrate windows1/2/3, append before3, correct identity before4. Fifteen serial processes cover three hash seeds and five cyclic arm orders. Sampling seed stays0; hash seeds are not independent sampling seeds. A separate regression checks inclusion frequencies across512 sampling seeds.

Measure weighted total-variation distance between each Primitive's sampled binding distribution and its full observed binding stream, collected separately on ID outside timing. Charge collection/export/calibration/reuse checks/build/train/query/all rebalances, including the final one. Exclude verification, TV audit, heap snapshots and persistence timing. Report index and collector object-size estimates separately; shared strings prevent exact summation. Verify complete results, state checkpoints, actual bytes/reloads and cross-process results/edge-order-normalized content digests. These are development worlds, not operational traces.

比较ID/频率/prefix8/reservoir8/reservoir32，采样方式均使用收益排序及最多2次复用。三个world，四区间各32/512 query，前八query相同，第一段尾部有效，之后为拒绝/未知target。集中world只有一个Primitive，构成完全相同照合前缀对照；其他world某些Primitive的前缀照合可能不足8条。第1/2/3区间采样计测，第3前追加、第4前修改identity。三hash seed×五循环顺序，共15串行process；sampling seed固定0，不把hash seed当独立采样seed。另以512个sampling seed回归各位置选择频率。
