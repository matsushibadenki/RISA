# G3.2 online validation development pilot / オンライン検証開発pilot / 在线验证开发试验

Status: [Done] development diagnostic; G3.2 final evaluation remains [Next]. The fixed input is [`g3_drift_online_validation_manifest.json`](../experiments/g3_drift_online_validation_manifest.json), and the complete output is [`g3-drift-online-validation-development-results.json`](g3-drift-online-validation-development-results.json). Run `python3 -m experiments.g3_drift_candidate_primed --manifest experiments/g3_drift_online_validation_manifest.json --output docs/g3-drift-online-validation-development-results.json` to reproduce it.

The pilot uses five development seeds and seven arms. Every arm gets the same 12 B and 12 A2 observations, A/B scoring panels, A1 candidate validation, Replay schedule, A2 validation opportunities at observed Events 1, 6 and 12, and a maximum of 3,600 additional supervised labels. Validation is attempted only when a warm merge proposal and its two parents exist. A missing proposal consumes zero labels; a rejected candidate still consumes the labels used to reach that decision. The runner protects both scoring panels from candidate evidence.

| Arm | A2 validation labels across five seeds | Final adopted merges | Final dormant candidates | Executed Primitive splits |
| --- | --- | --- | --- | --- |
| Full | 0 each | 0 each | 0 each | 0 each |
| Merge only | 3,600; 3,600; 3,600; 3,200; 3,600 | 1 each | 0 each | 0 each |
| No split | 3,600 each | 1 each | 2 each | 0 each |
| Split only, No merge, No dormancy, None | 0 each | 0 each | 0 each | 0 each |

[Done] 日本語: 同じラベル**上限**を与えても実消費は等しくならない。FullではB後にmerge提案が消え、A2の固定時点でも復活しないため、オンライン検証を1度も開始できなかった。No splitとMerge onlyでは提案が残り、A2中に検証済みmergeを再採用できた。No splitでは休眠も最終時点に残った。ただし全条件でPrimitive分裂が0であり、Fullにもmerge/休眠の機会がない。機構機会gateは**fail**で、この世界からsplit/merge/dormancyの因果的優位性は主張できない。A2復帰直後の保持率は全行0で、後からの再採用を保持と呼ばない。

[Done] English: Equal label **caps** do not imply equal label use. Full loses its merge proposal in B and cannot start validation at any scheduled A2 point. No split and Merge only retain a proposal and re-adopt a validated merge during A2; No split also ends with two dormant parents. Primitive splits remain zero in every arm, and Full has no merge/dormancy opportunity. The mechanism-opportunity gate therefore **fails**. This world cannot establish a causal benefit of split, merge or dormancy. Immediate A2 retention is zero in every row; later re-adoption is not retention.
