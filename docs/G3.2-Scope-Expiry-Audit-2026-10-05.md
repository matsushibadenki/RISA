# G3.2 validation-scope expiry audit / 検証scope失効監査 / 验证作用域失效审计

## Decision / 判断 / 结论

**日本語.** G3.2の開発を負の結果として完了する。5 seedすべてで、候補自身のsupport・counterexample・役割・lineageが不変なら、より広い親候補の範囲外更新後も既存検証を0追加ラベルで維持できた。候補scope内のcounterexample、役割、lineageを変えた15/15のmutationは再活性化を拒否した。一方、既存の固定予算controlではfullとno-mergeが同じ552/1,440に到達し、fullだけが8,000ラベル多く消費した。強い2-hop部分集合表は0追加ラベルで1,440/1,440だった。この開発gateは独立finalへ進む条件を満たさない。

**English.** Close G3.2 development as a negative result. Across all five seeds, validation survived a broader-parent update with zero additional labels whenever the candidate's own support, counterexamples, roles and lineage were unchanged. All 15/15 in-scope counterexample, role and lineage mutations were rejected for reactivation. In the existing fixed-budget control, full and no-merge both reached 552/1,440 while full spent 8,000 more labels; the strong two-hop subset table reached 1,440/1,440 with no extra labels. The development gate therefore does not justify an independent final run.

**简体中文.** 将G3.2开发阶段以负面结果完成。五个seed中，只要候选自身的支持证据、反例、角色及谱系不变，宽父候选的作用域外更新后均可在零新增标签下保留验证。作用域内反例、角色及谱系的15/15项变更全部被拒绝重新激活。既有固定预算对照中，full与no-merge均达到552/1,440，但full多消耗8,000个标签；强两跳子集表在零新增标签下达到1,440/1,440。因此开发门槛不足以支持独立最终实验。

## Contract and observed result / 契約と観測結果 / 契约与观测结果

| Case | Required behavior | Observed |
| --- | --- | --- |
| Broader parent changes outside a candidate's evidence scope | Keep identical validation; consume no labels | 5/5 seeds passed; four seeds exposed the unchanged scope after one A2 Event and seed 23 after two |
| Candidate counterexample changes | Expire validation | 5/5 rejected |
| Candidate role changes | Expire validation | 5/5 rejected |
| Candidate lineage changes | Expire validation | 5/5 rejected |

The audit does not weaken extension validation. A real in-scope support extension still requires the opt-in independent `CandidateExtensionValidator`; missing, overlapping or rejected development probes cannot transfer adoption. Full adoption remains the comparison path when the candidate contract changes.
