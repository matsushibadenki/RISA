# G3.4 — Primitive grounding index

🟢 [Done] Opt-in implementation and development regression audit.

## English

Ordinary composition can use a reconstructible summary of joint actor/target roles and identity equality. Repeated identical witnesses collapse into signatures. The full-evidence path remains the default and paired reference (`use_grounding_index=True` enables the index).

Three seeds × five incremental checkpoints × 80 queries yielded 1,200 correct answers, zero false accepts, and zero complete-result mismatches against full scans and JSON reloads. Candidate-enabled and disabled paths are both checked. The complete suite passes **284 tests**. Mixed roles, crossed bindings, equality, absent targets and direct corrected evidence are covered by regression tests.

Counts are per 80 queries for seed 419; all three seeds have the same work counts. Warm queries perform 224 signature checks; search nodes, Primitive scans and transition checks remain unchanged. Construction cost is measured separately. Ingestion/learning invalidate the cache; the next indexed access rebuilds it. JSON reload reconstructs it from primary evidence. Direct in-place Event/evidence corrections require explicit `invalidate_primitive_grounding(state)`.

The 490-byte summary is a serialized payload proxy, excluding Python containers, references and the existing Event log. It is not persisted and does not reduce saved state size. Whole-index rebuilding after updates remains linear in evidence references. Four signatures remain constant only in this repeated-role fixture; varied roles may increase signature count. Timings are descriptive sequential measurements, not a latency claim. This establishes neither structural quality superiority nor 100k end-to-end scaling. Forecast grounding is unchanged.
