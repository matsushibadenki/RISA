# G3.2 Nuisance Transfer under A→B→A Drift

## English

The previous transfer control established candidate-dependent predictions on
unseen context combinations. This development negative control now runs those
probes throughout A→B→A. Five seeds, all seven lifecycle arms, six A1 Events,
and twelve observations each in B and A2 are fixed in the manifest. Probe
contexts append an unseen nuisance tag; observations contain only the original
context. Both RISA and all tables receive identical Events, supplied device
roles, and query tags. Tags are never preselected as relevant. Each paired A/B
query is identical but its expected effect reverses. There is no return cue.

Four table controls are maintained: exact latest, exact count, subset latest,
and subset count. Subset latest retrieves the latest result from each most
specific matching scope and abstains when those scopes disagree. Subset count
votes within each scope, breaks outcome ties by recency, and then applies the
same scope-agreement rule. Complete multi-effect outcomes are kept atomic.
Neither subset table receives candidate-adoption labels.

| Model | A1 transfer accuracy | B exit | A2 exit | B recovery Events | A2 recovery Events |
| --- | ---: | ---: | ---: | --- | --- |
| RISA, all seven arms | 66.67% | 0% | 0% | censored | censored |
| Exact latest/count tables | 0% | 0% | 0% | censored | censored |
| Subset latest table | 100% | 100% | 100% | 5–7 | 5–6 |
| Subset count table | 100% | 100% | 100% | 8–10 | 8–11 |

All values cover the same five development seeds. Recovery uses the existing
95% reference and three-sample mean window. B references 1.0; A2 references
that model's A1 accuracy (2/3 for RISA, 1.0 for subset tables). Exact tables have
a zero A1 reference, so A2 recovery is undefined/censored. This fixture compares
held-out transfer, not merely online prediction of the training contexts.

RISA initially predicts warm via adopted specialized/merged candidates but has
no adopted cold candidate. During drift, its validated candidate applicability
is invalidated; the exact-context readouts cannot answer the nuisance probes.
All arms fail to recover transfer within the observed budget. RISA's measured
B structural touch ratio is 27.08–27.84%, with Replay work and group-wise touch
counts retained in the JSON. A low touch ratio without recovery is not evidence
of successful local adaptation. Replay costs for censored recovery include all
scheduled Replay calls in the phase; they are not costs of successful recovery.

The original priming protocol spends 1,200 A1 adoption labels in merge-enabled
arms and 800 in the other arms. No online adoption labels are consumed.
Postphase revalidation diagnostics, if present, are counted separately and do
not affect the measured B/A2 trajectories. These unequal budgets, together with
the failed mechanism-opportunity gate, prohibit an independent final ablation
claim. The `none` arm still receives the inherited specialized-candidate priming;
its switches control online discovery, not a candidate-free A1 state. It must
not be interpreted as a model with all structural knowledge removed.

Raw return retention is zero in RISA and subset tables. Every A query conflicts
with its paired B query, so perfect B prediction implies an immediate A accuracy
ceiling of zero without a return cue. RISA never reaches the B adaptation gate,
therefore its raw retention is not evidence of forgotten adapted knowledge.
This control diagnoses loss of transferable readout, and cannot establish
preserved A knowledge or a successful return mechanism.

Next: preserve this negative control and both subset baselines. Before changing
candidate adoption/invalidation, design an observable cue and coherent held-out
combinations that permit immediate return identification without directly
selecting a stored history key. Fix independent label budgets and initial
candidate states, then test whether validated structure can remain usable or
be revalidated locally. Do not retain stale adoption merely to improve scores.

## 日本語

5 seed×7条件で、未知の無関係タグを付けたprobeをA→B→A全phaseで採点した。全条件でRISAのA1精度66.67%はB終了時・A2終了時とも0%になり、観測予算内に回復しなかった。文脈部分集合の直近表はBで5〜7 Event、A2で5〜6 Event、回数表はBで8〜10 Event、A2で8〜11 Eventを要して100%へ回復した。部分集合表は採用用教師ラベルを消費しない。

RISAは採用候補による一般化を初期状態で示すが、driftで採用が失効すると完全一致readoutだけでは未知タグに答えられない。Bの構造touch比27.08〜27.84%は回復を伴わず、局所適応成功とは扱わない。回復未達のReplay量はphase全体の費用である。A1採用ラベルはmergeあり1,200件、その他800件で不一致、オンライン検証は0件。`none`も初期の特化候補採用を受け、全構造除去ではない。独立finalの因果比較には進めない。

復帰cueがなく、同じA/B queryの正解だけが逆なので、B完全適応時の即時A精度上限は0である。RISAはB適応未達のため、生の保持0を適応後の忘却と解釈しない。負例として残し、次は履歴キーを直接選ばない復帰cue、採用ラベル予算、初期候補状態を固定したworldを定義する。

## 简体中文

五个seed×七组条件在A→B→A各阶段评估添加未知无关标签的探针。全部RISA条件从A1的66.67%下降至B结束和A2结束的0%，在观察预算内未恢复。情境子集最近表在B用5至7个Event、A2用5至6个Event恢复至100%；子集计数表分别需要8至10及8至11个Event，无需采纳监督标签。

RISA初始能通过采纳候选泛化，但漂移使采纳失效后，完全匹配读取无法处理未知标签。B结构touch比例27.08至27.84%未伴随恢复，不能视为局部适应成功。未恢复时的Replay量包含整个阶段。A1采纳标签在启用合并条件为1,200，其他为800；在线验证为0。`none`仍接受初始特化候选采纳，并非移除全部结构。不能据此进入独立final因果比较。

没有返回线索，配对A/B的query相同而答案相反，因此完全适应B后的即时A准确率上限为0。RISA未达到B适应门槛，不能把原始保留0解释为适应后的遗忘。保留此负面控制，下一步固定不会直接选择历史键的返回线索、采纳标签预算及初始候选状态。
