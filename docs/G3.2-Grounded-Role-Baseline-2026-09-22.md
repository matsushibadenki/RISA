# G3.2 grounded role baseline / 役割条件付き具体遷移baseline / 按角色条件化的具体迁移基线

Status: [Done] development comparison; G3.2 causal evaluation remains [Next]. The [baseline implementation](../risa/evaluation/grounded_role_baseline.py) stores only the latest observed outcome for each action, supplied target-role set and context-tag set. It observes the same A1/B/A2 Events in the same order, scores each Event **before** observing it, and receives the same role labels as RISA. It has no split, merge, dormancy, Replay or validation labels. Its rule is fixed here; no seed-specific selection or threshold tuning is used. The [manifest](../experiments/g3_contextual_split_proposal_manifest.json) and [result JSON](g3-contextual-split-proposal-results.json) contain five paired development seeds and all RISA arms.

| Measure across five seeds | Role baseline | RISA global split | RISA contextual proposal |
| --- | --- | --- | --- |
| Immediate A2 retention | 0.5 each | 0.5 each | 0.5 each |
| B pre-update accuracy, 60 Events | 55/60 | 45/60 | 45/60 |
| A2 pre-update accuracy, 60 Events | 55/60 | 46/60 | 45/60 |
| B recovery Events, by seed | 4, 2, 3, 2, 4 | 7, 4, 6, 4, 7 | 7, 4, 6, 4, 7 |
| A2 recovery Events, by seed | 3, 4, 7, 3, 4 | 7, 7, 9, 5, 7 | 7, 9, 9, 5, 7 |

[Done] 日本語: 未見actor/targetの境界probeでも、baselineとRISAはA1 A=1.0、B A=0.5、B B=1.0、A2 A=1.0で同じだった。target roleとcontextは入力済みなので、最新の役割条件付き観測だけでこの世界を解ける。RISAの複雑な構造更新はこの比較で利益を示せず、条件付き分裂は1 seedでさらに回復を遅らせた。baselineは直近1件を優先する設計で急激な決定論的driftに強い。これは**この開発worldに対する負の結果**であり、未知のworld全般への順位ではない。保存byteはEvent履歴の保持範囲が異なるため、この表で直接比較しない。

[Done] English: On unseen-actor/target boundary probes, both models score A1 A=1.0, B A=0.5, B B=1.0 and A2 A=1.0. Supplied target roles and contexts let the last observed role-conditioned outcome solve this world. RISA's structural updates show no benefit here, and the contextual split delays recovery in one seed. The baseline's latest-observation policy is well matched to abrupt deterministic drift. This is a **negative result for this development world**, not a ranking across new worlds. Stored bytes are not directly compared because Event-history retention differs.
