# G3.4 joint-binding quality against a learned grounded table

## English

### Fixture and frozen comparison

A new two-step `prime → execute → done` fixture trains two role/identity families: operator acting on a distinct remote unit, and an autonomous self unit acting on itself. The held-out oracle is a separate ten-case truth table, not the training generator or either learner. It includes both valid families, wrong identity equality, crossed role pairs, missing/wrong actor roles, missing connected state and insufficient energy. All systems receive identical structured Events, supplied role information and identity relations. No applicability/adoption labels are supplied.

The first development run (v1, seeds101/211/307) accidentally coupled source parity with family parity. It discovered no candidates because each family had only one source. That diagnostic is preserved separately. V2 balances both sources within each family and fixes seeds419/523/631 and a new entity namespace before its run. Thresholds stay at candidate advantage≥0.05 and zero false accepts; no oracle labels or acceptance thresholds change to obtain a favorable outcome. These seeds change entity identities, not the semantic world rules. The ten-case design was already available during source auditing: this is independent held-out entity evidence in a development fixture, not an untouched final world or formal external preregistration.

Three episode checkpoints4/8/16 correspond to8/16/32 primary Events. Each checkpoint evaluates40 unseen cases per seed and compares:

- RISA world model with ordinary composer, candidate mode on.
- The same RISA composer with candidate mode off.
- A grounded contract table learned only from observed Events, with simple breadth-first search.

The table stores action, joint actor/target roles, equality, state/resource prerequisites, deltas, consumption and atomic outcomes. Episode ordering supplies its action successors; it receives neither oracle transition labels nor hand-authored successors. It shares only the pure transition kernel with RISA, not RISA's candidate discovery or search. A test confirms that training only the distinct family does not allow the unobserved self family.

### Results

Every checkpoint and seed scores **40/40**, with **zero false accepts**, for all three paths. Candidate advantage over the strong table is0, so its fixed≥0.05 gate fails. Eight positive cases per panel succeed; rejection alone cannot produce the score. Actor/target identities and Event/case IDs are disjoint from training. All complete RISA CompositionResults agree after JSON reload, with zero mismatches; evaluation leaves learned state unchanged.

| Events, each seed | Active RISA Primitives | Proposed candidates | Adopted candidates | Table contracts | RISA JSON payload bytes | Table + raw Events bytes |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 8 | 2 | 6 | 0 | 4 | 28,261 | 6,517 |
| 16 | 2 | 6 | 0 | 4 | 50,199 | 12,104 |
| 32 | 2 | 6 | 0 | 4 | 94,344 | 23,328 |

Counts and byte sizes match across these equal-length seed identities. Both payloads retain complete raw primary Events; the baseline byte count also includes its contracts and successor map. These are logical JSON sizes with a common encoder, not measured file-save sizes or equivalent-purpose system memory: RISA additionally stores graph, validation and learning metadata. The pilot does not establish compression. Structures/contracts stay constant, stored size grows nearly linearly, and held-out quality is saturated at the first checkpoint.

The table expands48 queue nodes per40-case panel. RISA's ordinary composer does not yet expose comparable expanded-node diagnostics; its search work is not inferred from returned path length. A matched planner/oracle decomposition is also absent. Consequently the joint G3.4 claim—reusable structure growth, lower marginal storage/search cost and higher unknown-problem success—is not demonstrated.

Six candidates are proposed but none is adopted. Candidate-on/off is therefore a negative opportunity control, not evidence that adopted candidates help or harm. We do not force adoption or add supervision solely to make this comparison positive. Fixed thresholds and the v1 source-confounding failure remain visible.

### Next

Instrument RISA composition search work directly and freeze a larger varied-world quality/growth fixture with new semantic rules, stronger counterexamples and sufficient candidate opportunities. Include same-planner world-model comparisons and account for any adoption labels. Retain the grounded-table control and this simple binding fixture as an applicability regression. G3.4 remains open; perception, recursive concepts and hardware expansion remain later stages.
