# G3.2 contextual split proposal pilot / 文脈別分裂提案pilot / 按情境分裂提案试验

Status: [Done] development-only negative result. Manifest: [`g3_contextual_split_proposal_manifest.json`](../experiments/g3_contextual_split_proposal_manifest.json). Complete output: [`g3-contextual-split-proposal-results.json`](g3-contextual-split-proposal-results.json). Reproduce with `python3 -m experiments.g3_split_drift_opportunity --manifest experiments/g3_contextual_split_proposal_manifest.json --output docs/g3-contextual-split-proposal-results.json`.

The experimental `TrainingOptions.enable_contextual_split_proposal` switch defaults to **false**. With it enabled, one clean Replay window scores each distinct selected evidence Event once by context. A proposal requires at least two evidence Events in each of two contexts, at least two errors and error rate ≥0.75 in one, error rate ≤0.25 in the other, and a rate gap ≥0.5. The existing global rule and its 0.6 threshold remain unchanged. Candidate specialization and merge are disabled in every arm. The comparison uses five development seeds, identical A1/B/A2 observations, scoring panels and Replay limits, and three arms: global split rule, contextual proposal plus global rule, and split disabled.

| Measure across five seeds | Global rule | Contextual proposal | Split disabled |
| --- | --- | --- | --- |
| Executed Primitive splits | 0 each | 1 each | 0 each |
| Immediate A2 retention | 0.5 each | 0.5 each | 0.5 each |
| B recovery Events | 7, 4, 6, 4, 7 | 7, 4, 6, 4, 7 | 7, 4, 6, 4, 7 |
| A2 recovery Events | 7, 7, 9, 5, 7 | 7, **9**, 9, 5, 7 | 7, 7, 9, 5, 7 |

### Readout intervention / 予測readoutの介入 / 预测读取干预

[Done] The same four A and four B scoring probes were evaluated at B exit, and A probes again at A2 exit. Removing all Primitives from a disposable state copy changes **zero predicted effects** in every seed and arm at these boundaries; the mean absolute score shift is 0.05 at B exit. Disabling recent-outcome readout also changes zero effects but shifts score by 0.5. Disabling candidate readout changes neither effects nor score because candidate adoption is disabled in this micro-world. These are component interventions, not a complete decomposition of grounded counts, graph patterns or interactions. They explain why more Primitive splits did not improve these boundary predictions; they do not prove Primitive effects are absent in every query or during the phase.
