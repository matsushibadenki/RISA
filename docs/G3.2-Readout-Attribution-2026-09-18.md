# G3.2 phase-wide readout attribution / 全phase予測寄与診断 / 全阶段预测贡献诊断

Status: [Done] development-only diagnostic. The experiment is [`g3_split_drift_opportunity.py`](../experiments/g3_split_drift_opportunity.py) with [`g3_contextual_split_proposal_manifest.json`](../experiments/g3_contextual_split_proposal_manifest.json). Full per-Event and transfer-probe traces are in [`g3-contextual-split-proposal-results.json`](g3-contextual-split-proposal-results.json).

Each pending Event is evaluated **before** it is learned. For that query, a disposable model copy removes Primitives, and query flags independently disable recent-outcome and candidate readout. The callback is checked against a before/after state snapshot and cannot change learning state. At A1/B/A2 boundaries, four independent synthetic probes use actor and target IDs absent from observations, while retaining the supplied `device` target role. All arms use the same probes and Event order. A component intervention measures a conditional readout effect; it is not a full decomposition of interactions or a model-versus-planner comparison.

| Arm, five seeds pooled | B pre-update accuracy (60 Events) | B flips without Primitives | A2 pre-update accuracy (60 Events) | A2 flips without Primitives |
| --- | ---: | ---: | ---: | ---: |
| Existing global split rule | 0.750 | 0 | 0.767 | 1 |
| Experimental contextual proposal | 0.750 | 0 | 0.750 | 2 |
| Split disabled | 0.750 | 0 | 0.767 | 1 |

[Done] 日本語: 条件付き提案だけがseed 23のA2第8 Eventをcoldと誤予測し、Primitive除去では正しいwarmへ戻った。これが同seedのA2回復遅延と整合する。seed 37でもPrimitive除去で1件の誤りが消えるが、全体提案・split無効側でも同様の1件があり、条件付き提案だけの増分ではない。B全60件ではPrimitive除去による予測効果の変化は0。recent outcomeの無効化はBで全体提案・split無効側に各1件の変化、条件付き提案では0件だった。候補採用はこの小世界で無効。

[Done] English: Only the contextual-proposal arm predicts cold for seed 23's eighth A2 Event; removing Primitives restores the correct warm prediction, consistent with its delayed A2 recovery. Removing Primitives also corrects one seed-37 Event, but that flip occurs in the global and split-off arms too. Across all 60 B pre-update queries, removing Primitives changes no predicted effects. Disabling recent outcomes changes one B prediction in each of the global and split-off arms and none in the contextual arm. Candidate adoption is disabled in this micro-world.

[Done] 简体中文: 只有情境式提案组将seed 23的A2第八个Event错预测为cold；移除原语后恢复为正确的warm，与该seed的A2恢复延迟一致。seed 37另有一次移除原语后纠错，但全局规则和关闭分裂的条件也出现同样变化，并非情境式提案独有。B阶段全部60次更新前查询中，移除原语均不改变预测效果。关闭近期结果读取在全局规则和关闭分裂组各改变一次B预测，在情境式提案组改变零次。本小环境禁用候选采纳。

The unseen-actor/target probe panel scores A1 A = 1.0, B A = 0.5, B B = 1.0 and A2 A = 1.0 in every seed and arm. Removing Primitives changes none of these effects. These queries reuse a supplied target role and known action/context, so success can come from role-conditioned grounded evidence; they do **not** establish recursive structure transfer. Query generation, role supply and the oracle labels were fixed before running this development comparison.

[Next] Keep the conditional proposal disabled. For G3.2, seek an informative fixture where a structural intervention changes **independent** pre-update or held-out outcomes favorably without increasing stable-context variants, Replay cost or false generalization. Compare with a role-conditioned grounded baseline on exactly the same probe panel before claiming a structural advantage. Do not tune the present proposal threshold to erase its negative case.
