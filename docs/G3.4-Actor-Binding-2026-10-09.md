# G3.4 ordinary composition actor/target binding repair

## English

### Cause and repair

The actor/target temporal regression's ordinary Primitive path accepted an observer acting on a powered device and a controller acting on itself, although its typed training evidence supported a controller acting on a distinct powered device. Candidate plans already checked these bindings; the ordinary path checked only target roles.

Ordinary composition now requires a **joint supporting Event witness** when actor/target roles or identities are specified and actor-typed evidence exists. The same witness must match actor roles and, if specified, target roles. With both concrete identities present, their equality/inequality must match that witnessed in the typed evidence. Role matches from different Events cannot be combined. A target-qualified request with missing actor roles abstains when actor-typed evidence requires them. Entirely unbound abstract composition and untyped legacy primitives retain their prior applicability. All search steps apply this guard, including candidate-off mode.

The equality constraint is an evidence-derived applicability hypothesis, not a universal prohibition on self-actions. An equal-identity training witness permits equal query identities; distinct and equal training witnesses can permit both. This repair does not check arbitrary graph-edge relations or cross-step identity consistency beyond the existing candidate-plan contracts. One-step forecast has no actor input API and remains a target-local forecast, not an actor-qualified plan.

### Fixed regression results

The saved manifest uses five seeds, 20 development and 40 final episodes per seed: 100 development / 200 final cases. Each fixed panel balances valid controller, observer, wrong target role, self-binding and missing-state cases. The existing generator/panels are regression controls, not a new independent final-world evaluation. Adoption thresholds remain unchanged.

| --- | ---: | ---: |
| Correctness | 100% | 100% |

Previously the seed29 ordinary regression scored 60%, with false-generalization rate0.5; the candidate scored100% and gained40 percentage points. After the repair both are100%, and the unchanged adoption gate rejects the candidate as redundant. Together with the preceding target-role repair, neither of these two simple temporal fixtures demonstrates candidate gain against the strengthened ordinary composer. Historical experimental artifacts remain unchanged; their older baseline differs from current code.

Focused tests verify wrong actor roles, wrong target roles, self-binding rejection, missing actor role, abstract use, same-identity training support and rejection of separately matched actor/target witnesses. Existing typed candidate constraint tests now expect the candidate-off baseline to reject the same invalid cases, rather than encoding its former bug as intended behavior. Full suite verification covers compatibility with other composition, prediction and planning paths. This is semantic repair, not a structure-growth/condensation result or a 100k performance verification.

### Next

Freeze independent quality fixtures and strong grounded controls sharing the same role/identity information. Include joint binding and graph-edge counterexamples, then measure storage, structure growth and search work alongside success. Keep planner capability separate from learned world-model quality. Do not force candidate adoption when a stronger baseline removes its measured gain.

## 日本語

通常Primitiveの合成がobserverの操作とactor=targetの自己束縛を誤受理した原因は、対象役割だけを照合し、actor役割と同一/別entityの関係を確認しないことだった。actorに型付き支持証拠がある場合、actor役割・target役割・双方の具体identityの等値/非等値を同じ支持Eventで照合する処理を、候補offを含む各探索stepへ追加した。別々のEventの役割一致を組み合わせない。対象を限定した要求で必要なactor役割が欠ける場合も棄却する。完全に未束縛の抽象合成と型なし旧Primitiveは既存仕様を維持する。

等値関係は型付き証拠からの適用仮説であり、自己操作を一律禁止する規則ではない。同一identityの学習例があれば同一identityのqueryを許可する。任意graph-edgeやstep間identity制約全体を修正したものではなく、actor入力のない1-step forecastは対象局所予測のまま。

固定5 seed・development計100件・final計200件で候補/既存経路とも100%、誤一般化0、候補利得0。seed29の旧既存60%・誤一般化0.5から改善し、既存採用gateは冗長候補として拒否した。既に確認済みの生成器・panelの修正回帰であり、新規独立finalではない。過去の結果artifactは変更しない。前回の対象役割修正と合わせ、単純時間系列2課題の候補優位性は強化baselineに対して消失した。

次は同じ役割・identity情報を持つ強い具体表との独立品質比較を事前固定する。joint binding・graph-edge反例と、保存量・構造数・探索量を同時測定し、planner能力と世界モデル形成を分離する。

## 简体中文

普通Primitive合成错误接受observer操作及actor=target自绑定，原因是仅检查目标角色，没有检查actor角色及同一/不同entity关系。存在actor类型化支持证据时，现在每个搜索step（含候选关闭）要求同一支持Event同时匹配actor角色、target角色以及具体identity等值/非等值。不能组合不同Event的分别角色匹配。限定目标但缺失所需actor角色时也拒绝。完全未绑定抽象合成及无类型旧Primitive保持原有行为。

等值约束是从类型证据得到的适用假设，并非统一禁止自操作；同一identity训练例允许同一identity查询。本修复不覆盖任意graph-edge及完整跨step identity约束，无actor输入的一步forecast仍为目标局部预测。

固定五seed、开发100及最终200case，两路径均100%、误泛化0、候选增益0。seed29普通路径从60%和误泛化0.5改善，原采纳gate拒绝冗余候选。这是已检查生成器/panel的修复回归，不是新独立最终评估；历史结果artifact不修改。结合之前目标角色修复，两种简单时间系列任务的候选优势在增强基线下消失。

下一步预先固定共享角色及identity信息的强具体表独立质量比较，包含joint binding、graph-edge反例，同时测量存储、结构数及搜索量，区分planner能力与世界模型形成。
