# RISA 可塑性と記憶強化のメモ

## 1. 目的

この文書は、人間の神経可塑性に見られる

- 繰り返すほど記憶が強くなる
- 使わない記憶は弱くなる
- 一緒に使われた構造が結びつきやすくなる
- 繰り返し構造が上位概念へまとまる

という現象を、RISA でどう再現するかを整理するための設計メモです。

現時点の結論は次です。

> RISA では、神経回路の可塑性に相当するものを、ノード活性・関係信頼度・共活性・抽象化による構造更新として導入できる

---

## 2. 4つの基本機構

### 2.1 使用頻度

よく参照・活性化される構造ほど、残りやすく、優先的に使われやすくする。

RISA では例えば次の量が対象になります。

- `usage_count`
- `evidence_count`
- `recent_activity`
- `stability`
- `reliability`

これは「よく使う経路ほど通りやすくなる」という可塑性の最小形です。

### 2.2 時間減衰

長期間使われない構造は、すぐ削除するのではなく徐々に弱める。

RISA では例えば次の振る舞いになります。

- `recent_activity` を減衰
- `energy` を減衰
- 一定以下で `dormant = True`

これは生物の忘却や休眠に近い設計です。

### 2.3 再活性化

関連構造が同時に使われたときだけ、結びつきを強める。

これはヘッブ則に近いです。

```text
一緒に発火したものは結びつきやすい
```

RISA では、

- 同一イベントで共に活性化されたノード対
- 同じ文脈で何度も同時に出る関係
- 予測と観測が一緒に支持された構造

を少しずつ強めるのが自然です。

### 2.4 構造の統合

繰り返し現れるパターンは、単発記憶のまま保持するのではなく、上位の抽象構造へまとめる。

例:

```text
dog run -> fatigue_up
human run -> fatigue_up
horse run -> fatigue_up
```

から

```text
concept:shared_run_fatigue_up
```

を作る。

これは「エピソードの反復から概念が結晶化する」ことに対応します。

## 4. なぜこの4つを分けるのか

一見すると全部「記憶強化」に見えますが、役割は異なります。

- 使用頻度: よく使うものを残す
- 時間減衰: 使わないものを静かに下げる
- 再活性化: 同時に意味を持つものを結び直す
- 構造統合: 反復から新しい概念を作る

この4つがそろうと、RISA は単なる保存系ではなく、

> 使われるほど育ち、使われないと眠り、同時に意味を持つものが近づき、繰り返しが概念になる

という可塑的な記憶系に近づきます。

---

## 5. 実装上の見方

### 5.1 ノード可塑性

ノード側では次の更新が中心になります。

- 活性時の `recent_activity` 増加
- 活性時の `energy` 回復
- 長期未使用時の休眠

### 5.2 関係可塑性

エッジ側では次の更新が中心になります。

- `evidence_count` の増加
- `reliability` の上昇
- `plasticity` の低下

ここでの `plasticity` は ANN の重みではなく、

> まだ変わりやすい関係か、すでにかなり固まっている関係か

を示す更新メタ情報です。

### 5.3 概念可塑性

概念ノード側では次が重要です。

- support が増えると安定化
- メンバーが増えるとエネルギー増加
- 長期低活性なら休眠候補
- 文脈衝突が増えたら将来は分裂候補

## 7. 重要な注意

可塑性は強すぎても危険です。

リスク:

- ノイズ共起を強化してしまう
- 一時的な流行に引きずられる
- 誤った結びつきが固定化する
- 例外を潰してしまう

そのため、強化には少なくとも次の制約が必要です。

- 時間減衰
- 文脈条件
- evidence の閾値
- 後戻り可能性

---

## 8. 結論

人間の「繰り返すほど記憶が強くなる」という現象は、RISA でもかなり自然に導入できます。

しかも RISA では、単なる数値強化ではなく、

- 構造の活性化
- 構造の減衰
- 構造の再結合
- 構造の抽象化

として実装できる。

この意味で、RISA の可塑性は

> 重みを強くする学習

ではなく、

> **構造を育て、眠らせ、再結び付け、まとめ上げる学習**

として設計するのが自然です。
