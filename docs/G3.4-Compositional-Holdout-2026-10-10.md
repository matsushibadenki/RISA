# G3.4 unseen combinations and dependency controls — 2026-10-10

## English

The [fixed protocol](G3.4-Compositional-Holdout-Protocol.md) ran three seeds × two worlds × three checkpoints,
with 20 cases per panel (360 case evaluations per arm). Each seed repeats the same semantic rules under new
identities. This is development evidence under supplied role/state/resource contracts, not a final evaluation
or an implementation of Memory Mosaics. No production learning or composition semantics were changed.

### Quality, per 20-case panel at every checkpoint and seed

| Arm | Independent world | Coupled world | Interpretation |
| --- | ---: | ---: | --- |
| RISA candidates on | 20/20 | 20/20 | All valid paths accepted, all negative probes rejected |
| RISA candidates off | 20/20 | 20/20 | Same result without candidates |
| Factorized contract table | 20/20 | 20/20 | Strong simple baseline ties RISA |
| RISA primitives with shared BFS | 20/20 | 20/20 | Shared-search comparison also ties |
| Whole-path table | 16/20 | 20/20 | Rejects four valid unseen complete paths in the independent world |
| Role marginals | 16/20 | 16/20 | Four false accepts: crossed roles and wrong identity |
| Reset resource | 18/20 | 18/20 | Two false accepts: insufficient shared energy |
| Drop ticket | 20/20 | 16/20 | Four false accepts: forbidden crossed paths |

Each independent panel contains eight positives; each coupled panel contains four. Thus correct rejection
alone cannot explain the result. Strong arms score 360/360 overall with zero false accepts. The invalid
independence controls show that the counterexamples detect the dependency each arm drops.

### Growth and work

RISA has five adopted ordinary primitives and 18 proposed/zero adopted candidates at every checkpoint.
The strong table has ten joint contracts. Candidate advantage is zero, failing the unchanged ≥0.05 gate;
candidate-on/off remains an opportunity control. Adoption labels are zero.

| World | Events | RISA logical JSON bytes | Table + raw Events bytes | Native grounding Event reads |
| --- | ---: | ---: | ---: | ---: |
| Independent | 24 | 110,222 | 29,250 | 424 |
| Independent | 48 | 199,873 | 47,894 | 848 |
| Independent | 96 | 378,995 | 85,230 | 1,696 |
| Coupled | 24 | 107,305 | 29,034 | 440 |
| Coupled | 48 | 193,770 | 47,390 | 880 |
| Coupled | 96 | 366,526 | 84,150 | 1,760 |

These equal-length identities yield identical sizes/counts across seeds. Native expanded nodes remain
46 (independent) or 48 (coupled) per panel, while evidence reads grow linearly. Both payloads retain raw Events;
RISA also carries graph/learning/validation metadata. This is not equal-functionality memory, measured latency,
or a compression win. The shared-BFS adapter's compilation cost is excluded from query counters.

### Integrity and limits

All 18 split audits have zero identity/ID/complete-heldout-path overlap and zero missing local action pairs.
Both binding families and both branches have two training sources at each checkpoint. All 720 native complete
CompositionResults match after JSON reload and with instrumentation disabled. Scoring leaves original and
restored learned states unchanged. A regression separately checks atomic receipt, consumed ready state and
zero remaining energy after a valid three-stage path. Panel quality itself measures Boolean goal reachability.

This supports composition of known, supplied-contract transitions beyond memorized complete trajectories and
shows why joint witnesses/shared resources/state dependencies must survive factorization. It does **not** show
automatic discovery of independence, candidate superiority, decreasing marginal storage/search work, or
success on an untouched semantic world. Quality already saturates at 24 Events; this does not identify the
minimum sample requirement. The two worlds deliberately change one dependency rule; seeds are not new worlds.

Keep the grounding read-model optimization next. Subsequently freeze richer semantic worlds and candidate
opportunities without relaxing adoption gates, and measure build/update costs alongside query costs. Do not
add a neural memory layer on the strength of this control alone. G3.4 remains open.
