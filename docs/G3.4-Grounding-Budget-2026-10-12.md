# G3.4 Lookup container budget / 接地索引予算 / 接地索引预算

## 日本語

`build_primitive_grounding(state, incremental=True, lookup_budget_bytes=8192)`で、Primitiveごとのlookup辞書コンテナに明示予算を指定できる。`None`は従来の無制限lookup、`0`は線形witness検索。構築・追加時に辞書の実サイズ差を追跡し、超過するとそのPrimitiveのlookupを破棄して完全なwitness行の線形検索に戻す。以後は明示再構築まで線形を維持し、追加のたびに失敗する再構築を繰り返さない。

予算対象はlookup本体・actor bucket・target辞書のコンテナであり、元のwitness集合、共有文字列、状態全体、RSSの上限ではない。判定直前にactor bucket一つまたはtarget辞書拡張分の一時超過があり得る。上限はPrimitive単位であり、全Primitive合計を制限しない。辞書の空き容量も`sys.getsizeof`に含める。役割対・identity条件・wildcardの意味は変更しない。

同じstateで訂正による無効化を行っても予算を引き継ぐ。load後は明示指定が必要で、保存形式は変えない。無効化後のincremental mode再選択は従来の契約どおり。予算は利用者が指定する資源制約であり、速度から推定した自動閾値ではない。既定の全走査も維持する。

実験は32証拠＋4追加、各側4/16/64役割、1/16 query、actor役割共有／分離の2分布、4反復。全走査・線形index・無制限lookup・8KiB予算lookupを循環順序で比較し、最後にidentity訂正＋無効化してcold query費用を含める。各段階の48ケースの完全結果と保存用内容、実ファイルのバイト列、復元結果を照合する。比較用の48 query照合は時間測定外。共有／分離は合成分布であり、独立した現実worldへの一般化の検証ではない。

## English

Add explicit `lookup_budget_bytes` per primitive: None preserves unlimited lookup; zero selects exact linear witness scans. Track actual dictionary-container size changes during build/append, discard a lookup when it exceeds the budget, and remain linear until rebuilding. Preserve role-pair, identity and wildcard semantics.

The limit covers lookup/actor-bucket/target dictionary containers, not canonical witnesses, shared strings, total state or RSS. One actor bucket or target-dictionary growth can transiently exceed the budget before discard. This is a per-primitive limit, not an aggregate limit. Carry the budget across invalidation on the same state; explicitly reselect it after loading. Persistence and default scan behavior remain unchanged.

Compare scan, linear, unlimited lookup and8KiB lookup over32 initial events plus four appends,4/16/64 roles per side,1/16 queries, shared/distinct actor-role distributions and four rotated repetitions. Include cold queries after an identity correction. Validate complete results, serialized updates, actual saved bytes and reloads separately from timing. These synthetic distributions do not establish generalization to independent real-world workloads.

## 简体中文

新增每个Primitive的显式`lookup_budget_bytes`：None保留无限lookup，0使用精确线性witness扫描。构建及追加时追踪字典容器实际大小，超限后丢弃lookup并保持线性，直到重新构建。角色对、identity及通配语义不变。

预算只限制lookup、actor bucket和target字典容器，不限制原始witness、共享字符串、整个状态或RSS。判定前可临时超出一个actor bucket或target字典扩容的大小；也不是所有Primitive的总预算。同一state失效后保留预算，加载后需显式指定。保存格式与默认扫描不变。

比较扫描、线性、无限lookup、8KiB lookup：32个初始事件加4次追加，每侧4/16/64角色，1/16 query，共享/分离actor角色及四次轮换。包含identity修改后的冷查询。完整结果、序列化、文件字节及恢复在计时外验证。两种合成分布不代表独立真实world泛化验证。
