# G3.2 Primitive split drift opportunity / Primitive分裂の開発検証 / 原语分裂开发验证

Status: [Done] development diagnostic only. Manifest: [`g3_split_drift_opportunity_manifest.json`](../experiments/g3_split_drift_opportunity_manifest.json). Complete output: [`g3-split-drift-opportunity-results.json`](g3-split-drift-opportunity-results.json). Reproduce with `python3 -m experiments.g3_split_drift_opportunity`.

The micro-world uses A1 warm → B cold → A2 warm with two observable contexts, five development seeds and paired split on/off runs. Both arms receive identical observations, scoring probes and Replay work. Candidate specialization and merge are disabled in both arms to isolate the Primitive split execution path. Replay runs after each newly observed Event; the observation and recovery budget is fixed.

| Measure | Split on | Split off |
| --- | --- | --- |
| Executed Primitive splits at final | 1–2 per seed | 0 |
| Immediate A2 retention | 0 in all five seeds | 0 in all five seeds |
| B recovery Events | 5, 6, 5, 7, 6 | 5, 6, 5, 7, 6 |
| A2 recovery Events | 7, 9, 9, 8, 7 | 7, 9, 9, 8, 7 |

[Done] 日本語: 分裂の**実行機会**は再現したが、このfixtureでは回復の改善は観測されなかった。両条件のReplay再適用Event数も各seed・phaseで一致した。したがって「分裂が作動した」と「分裂が役立った」を分けて扱う。固定actor/targetで効果が全context一斉に反転するため、contextで旧A知識を守れる世界ではない。5 seedはcontext順序の開発上の変化であり、独立final評価ではない。

[Done] English: The split **execution opportunity** is reproducible, but this fixture shows no recovery benefit. Replay reapplication counts are identical within every paired seed and phase. Execution and usefulness must be evaluated separately. The effect reverses in every context for a fixed actor/target, so context cannot protect old A knowledge here. These five seeds vary development context order; they are not an independent final evaluation.

[Done] 简体中文: 原语分裂的**执行机会**可以复现，但该环境未显示恢复收益。每对seed及阶段的Replay重新应用Event数也完全相同。必须区分“机制被执行”和“机制有用”。固定actor/target在全部context中同时反转，因此context无法保护旧A知识。这五个seed只改变开发环境中的context顺序，不是独立最终评估。
