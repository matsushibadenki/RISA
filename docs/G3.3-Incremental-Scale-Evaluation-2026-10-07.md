## Implementation / 実装 / 实现

日本語: 共活性だけの双方向隣接indexをgraph更新・復元時に構築し、予測の全edge走査を除いた。公開予測の根拠経路は従来と同じ先頭3件で打ち切る。学習前検証は同じ予測選択処理を使い、消費しない根拠IDと経路の構築を省く。公開`PredictionResult`の根拠は保持する。

English: Build a bidirectional coactivation-only neighbor index during graph updates and reload, removing full-edge prediction scans. Public provenance paths stop after the same first three paths. Pre-update validation uses the same prediction-selection code while omitting unused evidence-ID/path output. Public PredictionResult provenance remains intact.

简体中文: 在graph更新及恢复时构建仅共活性的双向邻接索引，消除预测中的全edge扫描。公开来源路径取与原实现一致的前3项。学前验证共享相同预测选择代码，仅省略不使用的证据ID及路径输出；公开PredictionResult保留来源。

日本語: 代謝は`dormant && energy == 0 && recent_activity == 0`の固定点を派生worklistから外す。活性化、共活性、概念報酬、新規nodeで再登録し、学習batchの境界で外部編集を再照合する。負の減衰率は全走査へ戻し、`TrainingOptions(enable_indexed_metabolism=False)`で従来の走査を比較できる。減衰の計算式・浮動小数点演算順序・episode処理は変えていない。

English: Metabolism removes fixed-point nodes satisfying `dormant && energy == 0 && recent_activity == 0` from a derived worklist. Activation, coactivation, concept rewards and new nodes register work again; training boundaries reconcile external edits. Negative decay rates use the full scan, and `TrainingOptions(enable_indexed_metabolism=False)` retains the scan control. Decay formulas, floating-point operation order and episode handling remain unchanged.

简体中文: 代谢将满足`dormant && energy == 0 && recent_activity == 0`的固定点节点移出派生工作表。激活、共活性、概念奖励及新节点重新登记，训练batch边界核对外部编辑。负衰减率回退全扫描，`TrainingOptions(enable_indexed_metabolism=False)`保留扫描对照。衰减公式、浮点运算顺序及episode处理不变。

日本語: 前提学習には完全なbefore観測を持つEventだけのaction indexを使う。証拠listの順序を保ちながら、派生setで重複登録を判定する。これらのindex/worklist/setは保存対象ではなく、Eventとgraphから復元するためschema変更はない。

English: Applicability learning uses an action index containing only fully observed before-state Events. Derived sets check membership while preserving evidence-list order. These indices, worklists and sets are reconstructed from Events/graph rather than persisted; no schema change is required.

简体中文: 前提学习使用仅含完整before观测Event的action索引。派生set判定重复，同时保留证据list顺序。索引、工作表及set从Event/graph重建，不持久化，无需schema变更。
