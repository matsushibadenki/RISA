# RISA 構造共有と知識創発のメモ

## 1. 目的

この文書は、
RISA が

- 構造を正確に保存できること

と

- LLM のように「知識を持っているような振る舞い」を示せること

が同じではない、
という問題を整理するための設計メモです。

現時点の核心は次です。

> 構造を大量に保存するだけでは、
> 知識らしい振る舞いは創発しない可能性がある

したがって、
RISA に必要なのは

> 構造の記憶
> +
> 構造の圧縮
> +
> 構造間の共有
> +
> 構造の再利用
> +
> 構造から未知の関係を生成する仕組み

です。

---

## 2. なぜ単純な構造保存では不十分か

例えば、

```text
鳥 ─has→ 翼
鳥 ─can→ 飛行
ペンギン ─is-a→ 鳥
ペンギン ─cannot→ 飛行
```

のように構造を明示保存したとします。

これは正確です。
しかし、
このままでは原則として

- 保存した関係
- 保存した例外

しか存在しません。

つまり、

> 記憶はできるが、
> 知識が創発しない

という事態が起こり得ます。

一方、
LLM 的な系では、
多数の経験が同じパラメータ空間へ圧縮され、
共有表現の中で

- 補間
- 類推
- 弱い一般化

が起こります。

この差はかなり本質的です。

---

## 3. LLM と RISA の違いをどう見るか

単純化すると、

LLM は

```text
多数の事例
  ->
重みを共有
  ->
概念・知識が創発
```

です。

RISA が目指すべきなのは、

```text
多数の事例
  ->
構造を共有
  ->
概念・知識が創発
```

です。

ここで重要なのは

> RISA の本質は
> 「構造を記憶すること」
> ではなく、
> 「構造間で何を共有するか」

にあることです。

---

## 4. 構造共有とは何か

RISA が単なる静的グラフを超えるには、
個別のノードやエッジだけでなく、
**再利用可能な構造パターン**
を共有単位として持つ必要があります。

例えば、

```text
A -> B -> C
D -> E -> F
G -> H -> ?
```

があるとき、
単なる知識グラフなら
それぞれ別データです。

しかし RISA が

```text
(A,B,C) ~ (D,E,F) ~ (G,H,?)
```

のような
**構造的類似**
を持てれば、

```text
? ≈ I
```

のような推論が可能になります。

このとき共有されているのは
個別ラベルではなく、

- 役割
- 順序
- 因果位置
- 文脈上の機能
- 再利用可能な変化パターン

です。

---

## 5. 知識の定義を修正する

RISA では、
知識を
個々のノードやエッジそのものと見るより、

```text
Knowledge
  =
reusable structural pattern
```

と見た方が自然です。

例えば
「支える」
という知識を、

```text
柱 -> 建物
脚 -> 机
骨格 -> 身体
根 -> 木
基礎 -> 組織
```

の個別事実群としてだけ持つのではなく、

```text
X
  -supports->
Y
```

という
**構造的不変量**
として抽出する。

すると、
未知の対象でも

```text
未知X -> 未知Y
```

から、
X は Y を支える役割かもしれない、
という推論ができます。

これは

> 記憶したことを答える

ではなく、

> 記憶していない知識を、
> 構造から生成する

ことに近いです。

---

## 6. RISA に必要な共有機構

RISA で知識らしさを創発させるには、
少なくとも次の波及が必要です。

```text
局所的な構造変更
  ->
類似構造
  ->
上位構造
  ->
時間的関連
  ->
因果的関連
  ->
役割的関連
  ->
構造パターン更新
  ->
新しい推論
```

重要なのは、
これを総当たりでやらないことです。

必要なのは、

- 局所更新
- 類似構造インデックス
- 上位概念への波及
- 再利用パターンの再評価

のような、
限定された共有経路です。

---

## 7. 関係は単純エッジで終わらせない

RISA の関係を、
単なる
`A -> B`
の線で終わらせると、
知識創発は弱くなりやすいです。

そこで関係そのものに、
例えば次のような多次元状態を持たせる考え方が有力です。

```text
r = (f, t, c, p, s, ...)
```

例:

- `f`: 関係の種類
- `t`: 時間
- `c`: 文脈
- `p`: 確信度
- `s`: 構造的位置

こうすると、
RISA は
静的グラフではなく、
**相互作用可能な構造場**
へ近づきます。

---

## 8. 研究目標の明確化

この問題を踏まえると、
RISA の研究目標は
次のように置くのが分かりやすいです。

> RISA における「知識が創発した」とは、
> 保存されていない関係を、
> 保存済み構造と現在文脈から生成できた状態である

つまり、

```text
Stored Information
!=
Available Knowledge
```

であり、

```text
Available Knowledge
  =
Stored Structure
  +
Structural Inference
```

です。

この定義にすると、
RISA の評価は

- 何個の事実を保存したか

ではなく、

- どれだけ再利用可能な構造パターンを持てたか
- そこから未保存関係をどれだけ導けたか

へ移ります。

---

## 9. ロードマップへの含意

短期的に必要な研究テーマ:

- 構造類似の表現
- 役割ベースのパターン共有
- 上位概念を介した波及更新
- 未保存関係を導く推論ベンチマーク

中期的に必要な研究テーマ:

- 構造共有インデックス
- 構造的不変量の抽出
- 例外を保ったままのパターン再利用
- 類似構造からの仮説生成

長期的な方向:

- 構造記憶とニューラル表現の協調
- 知識創発を世界モデル推論へ統合
- 学習器が変わっても共有構造を引き継ぐ基盤化

---

## 10. 結論

RISA は
「構造を記憶する仕組み」
だけでは不十分です。

本当に目指すべきなのは、

> 構造を記憶し、
> 構造を圧縮し、
> 構造間で共有し、
> 構造を再利用し、
> 構造から未知の関係を生成すること

です。

この最後の

> 保存されていない関係を生成できるか

を、
RISA における
「知識が創発した」
判定基準に置くのが、
かなり有力だと考えられます。
